# Lizenzgrenzen

Dieses Planungspaket legt keine einheitliche Open-Source-Lizenz für das künftige Produkt fest.
Die Veröffentlichung eines Repositories ist nicht gleichbedeutend mit der Erlaubnis, sämtliche darin enthaltenen Daten beliebig neu zu lizenzieren.

Eigener Code, redaktionelle Texte, OSM-/ODbL-Daten, optionale OPFF-Inhalte, Händlerfeeds, Herstellerbilder und weitere offene Datensätze benötigen getrennte Rechtehinweise.

Vor Live-Import: Source Registry und tatsächlichen Datenfluss prüfen. Keine „MIT gilt für alles“-Datei erzeugen. Die maßgeblichen Texte fremder Lizenzen aus verifizierten Primärquellen übernehmen, soweit ihre Verbreitung erlaubt ist; keine Lizenzbedingungen selbst paraphrasieren und als Volltext ausgeben.
